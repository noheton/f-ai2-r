\section{The Executable Skill}\label{sec:skill}

A method that lives in a PDF of guidelines depends on humans
remembering to follow it. We package aiprov instead as a
\emph{skill}: a versioned bundle of instructions and tools that an AI
agent loads and operates. The method's rules become the agent's
operating rules: log your own activities, record claims at
\texttt{ai-confirmed} at most, never fabricate telemetry, and never
grant a human-only rung.

\textbf{Live preview as oversight affordance.} Effective oversight of
a fast-moving AI collaborator needs a continuously current view of the
deliverable; the EU AI Act's human-oversight
expectation~\cite{eu-ai-act2024} becomes a user-interface property
(Figure~\ref{fig:environment}, right panel). The judgement stays the
human's; only its transcription is automated.

\textbf{Structure before prose.} The agent first lays down each
section's principal structure, its argument flow, evidence, and figure
and citation plan, as a reviewable skeleton; prose is a separate later
pass. The operator can contest structure cheaply before any prose
exists to defend it, and both passes are logged.

\textbf{CI.} Every push validates the graph, renders the dashboard,
regenerates the disclosure, and compiles the paper; a conformance
violation blocks the build, and CI runs can be logged as \texttt{Build}
activities of a \texttt{ToolAgent}.

\textbf{Worked example (prospective design).} The workflow is not
specific to papers. In a study such as the comparison of power and
amplitude control in continuous ultrasonic welding of
CFRPs~\cite{ultrasonic-welding2025}, each raw record (power trace,
scan, test protocol) is a vendored \texttt{Source} with its content
hash; each analysis run is a logged \texttt{Build} activity that used
those sources and generated the derived tables and figures; data
acquisition and scripts are \texttt{ToolAgent}s, the assistant an
\texttt{AIAgent}. A finding is a claim generated by the analysis
activity: the AI may grant \texttt{ai-confirmed} after cross-checking
the derived data, the experimenter spot-checks the test table for
\texttt{human-confirmed}, and the comparative conclusions deserve
\texttt{human-read}. This is a design, not a deployment; integration
with the shepard platform is planned
(Section~\ref{sec:conclusion}).

\textbf{Auditability at the command line.} An auditor clones the
repository and runs the same tooling as the authors. Three checks need
no trust in anyone's honesty: re-running the validator replays every
invariant against the graph as it stands; \texttt{hashes} re-hashes
vendored files against the recorded digests (an exact match is required
for literature evidence); re-resolving a recorded DOI confirms the
citation metadata still matches the registry. Two further checks read
rather than execute: the activity log tells the auditor \emph{who}
granted each rung, and the transcript shows the dialogue in which a
contested decision was made. Success is quiet and failure is loud
(Figure~\ref{fig:cli}): a violation names the offending node and exits
nonzero, and a refused operation says why and what would make it
legitimate. For the human rungs the gate either blocks for lack of
access material or prints where the review copy sits, so the human step
starts with the evidence in hand.

\textbf{Versions and the two code lines.} The skill line is the bundle
in the paper repository (Apache-2.0; v0.21 measured, v0.22 current);
the open package (\url{https://github.com/noheton/aiprov}, MIT, tag
v0.1.0) carries the vocabulary and the core commands and has its own
graph. A portable core runs on every Agent Skills client; three
per-client shims (a Stop hook, the transcript exporter, usage
aggregation) adapt it, and the exporter masks stored secrets. Snapshots
are immutable and changes are logged, so the meta-experiment can cite
the exact method version in force at any point, and commits bind to
artefacts. The skill is also the transferable unit: the bundle that
wrote this paper is the intended integration payload for the shepard
fork of Section~\ref{sec:conclusion}.
