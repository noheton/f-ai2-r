# /aiprov

Permanent identifiers for the **aiprov** vocabulary: a W3C PROV-O
extension for recording AI-in-the-loop research work (agents, activities
with inference telemetry, claims, sources, and a verification ladder
with human-only rungs).

- `https://w3id.org/aiprov/ns#<term>` — vocabulary terms; content
  negotiation serves the Turtle schema to RDF clients and the rendered
  schema to browsers.
- `https://w3id.org/aiprov/` — the project repository.

Canonical source: <https://github.com/noheton/f-ai2-r>
(`assets/aiprov-schema.ttl`).
